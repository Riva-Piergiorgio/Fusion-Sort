# Fusion-Sort
Il Fusion Sort procede attraverso una sequenza di passate dell’array. In ciascuna passata l’array viene suddiviso in gruppi adiacenti di dimensione potenza di 2. Ogni coppia di gruppi viene fusa in un unico gruppo ordinato. Nella prima passata la dimensione dei gruppi è pari a uno; nelle passate successive la dimensione raddoppia (1-2-4-8...).
